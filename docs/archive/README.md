# Archived appendix: fixed-strength calibration

[`fixed_strength_appendix.pdf`](fixed_strength_appendix.pdf) contains the two
appendix sections that the arXiv version of the paper keeps here: the earlier
fixed-strength calibration (Appendix I) and additional diagnostics for RQ2–RQ7
(Appendix J), as 16 pages of the paper build of 2026-10-31.

Inside the PDF, Appendices I and J refer to its own sections. References to
Sections 1–5 and Appendices A–H point to the arXiv paper, whose numbering they
match, and citations refer to the paper's bibliography.

The released `calibration: fixed_strength` and `review_mode: source_line`
settings run the configurations documented here; see
[ToolQA Full](../toolqa.md).
